# Prompts

Two reusable briefs for a coding agent, both safe to publish:

- [`review-project.md`](review-project.md) — UI/UX + architecture review of this
  repository. It is explicitly a *fix* brief: no feature removal, no extra
  safety restrictions, keep the suite green.
- [`publish-repo.md`](publish-repo.md) — preparation and release: real
  screenshots from `demo/`, README structure, repository hygiene, `gh` publish
  and an acceptance checklist.

Organization-specific runbooks (internal hostnames, gateway names, account
conventions) are intentionally **not** in this repository; keep them in your own
private docs. `docs/AGENT-GUIDE.md` is the public, provider-agnostic setup guide.
